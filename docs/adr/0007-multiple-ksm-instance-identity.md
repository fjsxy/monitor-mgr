# 每集群支持多个独立 KSM 实例，名称直接作为 CR 身份

一期一个已注册集群可管理多个 KSM 实例，平台纳管实例分别保存配置草稿、发布版本和运行状态，并继承所在集群的权限。

根据 2026-10-14 页面评审，用户创建前填写名称，直接作为 KubeStateMetrics CR 的 metadata.name；不支持中文，不再自动生成 CR name 或另设显示名称。名称按 Kubernetes DNS subdomain 规则校验，同名资源不可接管。下发开始后保护名称，首次创建成功后名称固定；改名通过新实例完成，以保持 UID、工作负载和管理历史的对应关系。平台未纳管实例仅允许查看。

此结论取代前一版“固定长度生成 ID 与可修改显示名称分离”的命名约定，其他多实例和资源身份边界保持有效。
