# 资源身份不明时停止写入，重建使用新实例

一期只更新或删除与平台已确认创建关系及保存 UID 一致的 CR；首次创建响应丢失且尚未保存 UID 时，不根据同名、相同配置或 labels 自动认领，结果待确认时也不因超时或重启解除变更保护，以避免将恢复可用性的尝试变成对既有资源的接管。

这一选择牺牲自动恢复便利性，由用户在集群侧处理身份不明的资源；删除后重建、namespace 迁移及 Agent 容量调整采用新实例、新 CR name 和新 PVC，保留原管理历史，避免旧卷误复用。具体状态与处理规则见 [确定配置发布、漂移与删除状态机](https://github.com/fjsxy/monitor-mgr/issues/8#issuecomment-6142918240)。
