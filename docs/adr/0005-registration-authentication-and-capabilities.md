# 注册要求可核验身份，组件能力单独决定下发资格

一期集群注册要求 TLS、连通、集群 UID 关联检查和 authentication.k8s.io/v1 SelfSubjectReview 非匿名身份核验通过，以获得 API server 识别的有效访问身份，避免将公开接口或权限检查成功当作身份核验；缺少该接口的 Kubernetes 1.19 不纳入一期注册范围，以减少旧版本专用认证判定。

组件 CRD、支持版本或业务权限不足时允许登记集群，但逐项展示原因并禁止受影响组件下发，发布时按实际目标 namespace 和操作再次核验权限，以区分集群已纳入管理与具体观测组件可用这两个事实。
