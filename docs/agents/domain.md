# 领域文档

本仓库采用 single-context：根目录 `GLOSSARY.md` 保存领域术语，`docs/adr/` 保存架构决策。

## 探索前读取

- 阅读根目录的 `GLOSSARY.md`。
- 阅读 `docs/adr/` 中与当前工作相关的 ADR。
- 文件不存在时直接继续，不报告缺失，不提前建议创建。
- 术语或决策实际得到确认后，由 domain-modeling 按需创建文档。

## 使用领域术语

Issue 标题、方案、假设和测试名称中的领域概念使用 GLOSSARY 定义的术语，遵守其中明确排除的同义词。

需要的概念尚未收录时，先判断是否引入了项目未使用的概念；确有缺口时，留给 domain-modeling 处理。

## ADR 冲突

方案与已有 ADR 冲突时，明确指出 ADR 编号、冲突内容和重新讨论的理由。
