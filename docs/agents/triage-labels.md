# Triage labels

下表将 skills 的五个 triage 角色映射到本仓库的标签。

| 角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求明确，可交由 agent 自主实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

Skill 提及 triage 角色时，使用对应的仓库标签。
以后调整标签名称时，修改“仓库标签”列。
